重點概念

Key Concepts · 基礎模型 → Transformer/擴散模型 → 優劣勢 → AWS 服務
🏗️
01

基礎模型 (FM)

Foundation Models

在海量資料上預訓練的大型模型，可被少量調整後用於多種下游任務，是生成式 AI 的核心。

🔤
02

Transformer LLM

Transformer & Tokens

以 Token/Embedding 表示文字語意關係（如 puppy:dog = kitten:cat），支援分類、生成、翻譯、程式碼生成。

🌫️
03

擴散模型

Diffusion Models

正向擴散逐步加入雜訊，反向擴散逐步去除雜訊以生成影像；Stable Diffusion 在潛在空間運作以提升效率。

✅
04

生成式 AI 優勢

Advantages

適應力（Adaptability）、回應力（Responsiveness）、簡易性（Simplicity）三大優勢，降低開發門檻。

⚠️
05

生成式 AI 限制

Limitations

輸出品質不穩、可能產生誤導/有害內容、對齊挑戰（HHH：有幫助、誠實、無害）、可解釋性與非確定性問題。

🔬
06

可解釋性方法

Interpretability

本質分析（Intrinsic）適用低複雜度模型、可解釋但效能較低；事後分析（Post-hoc）可用於複雜模型解釋輸出。

💰
07

Bedrock 定價與成本

Bedrock Pricing

按需模式依「輸入 Token 數 + 輸出 Token 數」計費；也可選用 Provisioned Throughput 或自訂模型應對吞吐需求。

🧪
08

GAN 與 VAE

GANs & VAEs

GAN：生成器與判別器互相對抗直到生成資料無法被辨識為假；VAE：編碼器將資料映射至低維潛在空間再解碼生成。

✓

隨堂測驗考點

Knowledge Checks
Knowledge Check 1
Amazon Bedrock 按需模式如何收費？
✓

依輸入與輸出的 Token 數量計費，而非 API 呼叫次數或訂閱制。

Knowledge Check 2
LLM 客製化方法依「維運負擔」由低到高如何排序？
✓

Prompt Engineering → RAG → 微調（Fine-tuning）→ 自行預訓練模型，維運負擔遞增。

⭐

一句話總結

掌握「基礎模型能力來源（預訓練）× 優劣勢 × Bedrock 計費方式」，這是 Domain 2 出題重心。
