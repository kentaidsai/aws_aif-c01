1

重點概念

Key Concepts · AI/ML/DL 定義 → 資料型態 → 學習方式 → 生命週期 → 評估指標
🧠
01

AI / ML / 深度學習

AI vs ML vs DL

AI 是最大範疇，ML 是其子集（從資料學習模式），深度學習是用神經網路的 ML 子集。

ML 需人工選特徵，DL 可自動學特徵但成本更高
🗂️
02

四種資料型態

Data Types

結構化（RDS/Redshift）、半結構化（JSON, DynamoDB）、非結構化（S3）、時間序列資料，各有對應儲存服務。

🎯
03

監督式學習

Supervised Learning

使用標記資料訓練，分為分類（二元/多元）與迴歸（連續數值）兩大問題類型。

SageMaker Ground Truth 用於資料標記
🔍
04

非監督式學習

Unsupervised Learning

無標記資料，透過分群（Clustering）發現客群結構，或異常偵測找出離群值。

客戶分群 · 信用卡詐騙偵測
🎮
05

強化學習

Reinforcement Learning

代理人（Agent）在環境中透過試誤（trial-and-error）行動，以最大化累積獎勵學習最佳決策。

自駕車軌道訓練
⚖️
06

過度配適 / 配適不足

Overfitting / Underfitting

過度配適：把訓練資料學太細，無法泛化新資料；配適不足：模型太簡單，訓練與新資料表現都差。

⏱️
07

即時推論 vs 批次轉換

Real-time vs Batch Inference

即時推論需持久端點、低延遲高吞吐但持續計費；批次轉換適合離線大量資料、成本效益高。

SageMaker 四種推論模式：即時/批次/非同步/無伺服器
🔄
08

ML 生命週期

ML Development Lifecycle

定義商業目標 → 建構問題框架 → 資料處理 → 模型開發（訓練/調參/評估）→ 部署 → 監控，並持續反覆優化。

🧹
09

資料處理三階段

Data Processing

收集（ETL、AWS Glue）→ 前處理（清理、切分 train/validate/test）→ 特徵工程（選取/轉換特徵）。

AWS Glue DataBrew：點選式資料轉換
📊
10

分類評估指標

Classification Metrics

混淆矩陣衍生出 Accuracy、Precision、Recall、F1-score、FPR、Specificity，各自反映不同錯誤代價的重視程度。

F1 平衡 Precision 與 Recall
📈
11

迴歸誤差指標

Regression Error Metrics

MSE 平方誤差平均、RMSE 開根號更貼近原單位、MAE 絕對誤差平均，用於評估連續值預測準確度。

🛠️
12

MLOps

Machine Learning Operations

將 DevOps 原則套用到 ML：IaC、版本控制、持續監控與自動重訓，SageMaker Pipelines 可端到端編排。

✓

隨堂測驗考點

Knowledge Checks
Knowledge Check 1
歷史音檔要轉文字並比對品牌關鍵字，該用哪個 AWS 服務與模式？
✓

Amazon Transcribe 批次轉錄工作（資料已存在 S3，非即時，屬離線批次情境）。

Knowledge Check 2
要從文字客服回饋辨識全球情緒，該用哪個服務？
✓

Amazon Comprehend（NLP 服務，可萃取情緒、實體、關鍵詞）。

Knowledge Check 3
ML 生命週期中「特徵工程」階段的最佳描述為何？
✓

在資料準備階段選取並轉換變數以強化訓練資料集，提升模型效果。
