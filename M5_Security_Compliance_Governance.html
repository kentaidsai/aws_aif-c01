1

重點概念

Key Concepts · 共同責任 → IAM → 加密與監控 → 治理與法規
🤝
01

共同責任模型

Shared Responsibility Model

AWS 負責「雲端本身的安全」（實體、硬體、網路、虛擬化）；客戶負責「雲端內的安全」（作業系統、應用、防火牆、帳號）。

🔑
02

IAM 核心概念

IAM Users, Groups, Roles

User 代表個人身份，Group 讓政策批次套用，Role 提供臨時憑證；最佳實務是用角色取代長效憑證，並遵循最小權限原則。

SageMaker Role Manager 簡化角色建立
🔒
03

靜態與傳輸加密

Encryption at Rest & In Transit

SageMaker 預設對儲存資料加密（可用 AWS KMS 管金鑰）；傳輸則透過 TLS/SSL，分散式訓練可另啟用節點間加密。

🕵️
04

偵測與稽核服務

Detection & Auditing

Amazon Macie 掃描 S3 找出敏感資料（PII）；AWS CloudTrail 記錄所有 API 呼叫供稽核追蹤。

🌐
05

VPC 與 PrivateLink

VPC & PrivateLink

將 SageMaker 部署於私有子網路並停用網際網路存取，透過 VPC 介面端點（PrivateLink）安全連接 AWS 服務。

🎯
06

AI 系統弱點

AI System Vulnerabilities

訓練資料、輸入輸出、模型本身（反演/竊取）與 LLM（Prompt Injection）皆可能是攻擊面，需全生命週期防護。

📇
07

模型治理工具

Model Governance Tools

SageMaker Model Registry 目錄化管理模型版本核准；Model Cards 記錄用途與風險；ML Lineage Tracking 視覺化端到端工作流程。

📜
08

合規與稽核服務

Compliance Services

AWS Artifact 隨需取得合規報告；Audit Manager 依框架收集稽核證據；Config 監控組態；Inspector 做安全評估；Trusted Advisor 給優化建議。

🌍
09

新興 AI 法規標準

Emerging AI Regulations

ISO 42001/23894 評估管理風險、EU AI Act 依風險分級（不可接受/高風險/未受規範）、NIST AI RMF（治理/對應/衡量/管理）。

🗃️
10

資料治理三支柱

Data Governance Pillars

Curate（確保品質）、Understand（可發現與理解，如資料目錄/血緣）、Protect（隱私、安全與存取的平衡）。

AWS Lake Formation · Glue Data Catalog
🪜
11

生成式 AI 安全範疇矩陣

GenAI Security Scoping Matrix

從使用公開生成式 AI 應用到自行訓練客製模型，五個範疇的治理與合規責任隨自訂程度遞增。
